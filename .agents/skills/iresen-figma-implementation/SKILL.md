# Reference implementation

Read [reference handling](../../../docs/references/README.md),
[the asset inventory](../../../docs/asset-inventory.md) and
[DESIGN.md](../../../DESIGN.md). Inspect the actual reference and current component;
record which file/frame/version is available and what it establishes.

Editable Figma data can establish measured structure. Screenshot exports establish
composition, not exact tokens, behavior, mobile/RTL layouts or factual truth.
Follow the host's mandatory Figma skill prerequisites before calling Figma tools;
this local skill does not replace them. A usable export can support implementation
without live Figma access.

Map the reference to approved page IDs, current SVGs and shared components. Replace
absolute prototype positions with responsive layout. Correct weak contrast,
hierarchy, content fit or interaction semantics and explain material departures.
Sample numbers, contacts and facilities need evidence; do not crop full screenshots
into production images or recreate delivered logos.

Derive and inspect mobile and Arabic behavior with
[responsive guidance](../iresen-responsive-layout/SKILL.md), then
[visual QA](../iresen-visual-qa/SKILL.md). Report fidelity, intentional differences
and unverified details without claiming pixel-exact extraction from screenshots.
