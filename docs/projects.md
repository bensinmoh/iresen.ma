# Collaborative projects

## Current state — 2026-10-12

The owner withdrew the complete demonstration catalogue. The canonical FR/EN/AR
page and its original hero remain, with the message “Les projets seront bientôt
mis à jour” and working EN/AR adaptations. There are no records, filters,
pagination, project detail drawer, professor placeholders or consortium wordmarks.

The 24 fictional JSON records, 72 localized PDFs, their manifest/generator and
six exclusive card images have been removed. Old `/api/projects/:id/note` URLs
return 404 with no-store. No CMS data migration/deletion is involved: the source
was an isolated file, never an institutional project collection. Publication,
patent, career and call collections remain independent.

All five anchors remain: `featured-results`, `find-project`, `project-catalogue`,
`understanding-results`, `related-capabilities`. Old query parameters do not revive
a withdrawn record. Search describes the empty catalogue; no project records or
notes are searchable. The hero remains the only served project-specific image
reference. Source hashes of withdrawn imagery remain in `projects-assets.json`.

A real project database, verified contacts/consortium evidence, publication workflow
and new downloads require a separately commissioned implementation. The current
empty page makes no commitment to a date, funding, results or commercial adoption.
No deployment is authorized by this change.

## Historical evidence

The 2026-10-11 implementation is retained in Git history and dated validation and
changelog entries. It is not the current product contract. The withdrawal supersedes
all previous demo, detail-panel, professor, logo and note-download instructions.
