# Internationalization

The website uses French (`fr`), English (`en`) and Arabic (`ar`). French is the editorial default. All public URLs use an explicit locale prefix; the unprefixed root redirects deterministically to French.

## Routing and content

Stable page identifiers and localized paths live in `src/lib/site.ts`, with locale routing in `src/i18n/`. Language switching resolves the equivalent current page instead of always returning to the homepage. Later dynamic records need stable IDs plus per-locale slugs and publication eligibility.

UI catalogs live in `src/messages/` and use ICU messages. CMS translations are separate. Buttons, errors, empty states, metadata, accessible labels and navigation require all three catalogs. Missing CMS translations remain unavailable rather than indexing fallback content.

Approved French routes are recorded in [route-map.md](route-map.md). The implementation's centralized route configuration defines English/Arabic counterparts; changes must preserve page boundaries and equivalents.

The `PageSections` UI catalog provides headings and short draft content notes for
all 22 pages in FR/EN/AR. Shared section IDs and order live in
`src/lib/page-sections.ts`; `isSupportedAnchor` includes both sections and nested
subtopics, so equivalent-page language switching preserves their valid
fragments. These notes describe content to prepare, rather than approved
institutional translations. See [the section guide](page-sections.md).

## Arabic and formatting

Set HTML `lang` and `dir` correctly. Use CSS logical properties for spacing, positioning and alignment. Mirror directional UI where meaningful; preserve logo geometry and the physical top-left/bottom-right brand corner signature. Use `bdi` for mixed-script names, URLs and identifiers when required.

Use `Intl` for locale-aware dates/numbers. Store instants in UTC, show material Moroccan event deadlines in `Africa/Casablanca`, and state the timezone. Do not hardcode Morocco's UTC offset.

Licensed, self-hosted Plus Jakarta Sans (normal variable 200–800) serves Latin and the owner's selected Alexandria (normal variable 100–900) serves Arabic. Script selection covers mixed-language UI in every locale; see [font provenance](fonts.md). Test Arabic shaping and line-height independently; avoid letter-spacing Arabic text.

## Verification

Check root redirect, every route in all three languages, equivalent-page switching with supported section anchors, missing locales, long labels and Arabic direction. Check 320px reflow, keyboard navigation and zoom. Before launch add realistic translated content and dynamic-resource tests; section placeholders do not validate editorial quality. See [validation](validation.md) for executed checks and their revision-specific limits.
