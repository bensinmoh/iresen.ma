# ADR 0003: owner-selected primary blue

Date: 2026-10-07. Status: accepted.

The owner's latest correction explicitly selects **#296BB4** for the website. Use this value for the primary-blue and focus tokens and future design work. Navy stays #12345A; the other supplied palette colors stay as recorded in the color book.

The supplied color book v0.9 specifies #296BB4, and all current blue-bearing SVGs use #296BB4, including the latest corrected favicon. Earlier #256BA2 source versions are superseded and preserved privately. Website tokens follow the selected color-book value. Preserve all source files and original SVG colors/geometry. Any future vector color transformation must be intentional and recorded; do not independently recolor the wordmark.
